# IB merger model

*Last updated: 2026-09-20*

Investment-banking M&A pet project: a simulated Swiss bank acquisition with three fictional banks.
All data is invented for education; nothing here is financial, legal, tax or M&A advice.

| Path | What it is |
|---|---|
| [`app/`](app) | Streamlit risk workbench: edit the banks' loan books, push a macro scenario through them, and see risk by client type and region under Swiss GAAP and capital rules. See [`app/README.md`](app/README.md). |
| [`books/`](books) | Loan-book workbooks (xlsx) for the three banks. |
| [`ma_decision/`](ma_decision) | Merger model (xlsx), decision memo (docx) and decision brief (html). |
| [`GLOSSARY.html`](GLOSSARY.html) | Glossary of the terms used. |
